# Kavis Pharma Website Recreation

## 1. Project Description
Recreate the Kavis Pharma pharmaceutical company website as a modern React SPA. The website showcases a premier pharmaceutical manufacturer with a 50-year history, featuring their services, quality commitments, and corporate information.

## 2. Page Structure
- `/` - Home (hero slider, services, about, quality services, stats, research, certifications)
- `/about` - About Us
- `/career` - Career
- `/contact` - Contact Us

## 3. Core Features
- [x] Hero slider with multiple slides and auto-rotation
- [x] Animated stats counter section
- [x] Image carousel for research section
- [x] Responsive navigation with mobile hamburger menu
- [x] Scroll animations (fade in, zoom in)
- [x] Footer with company info, quick links, and contact details
- [x] All pages with shared navigation and footer

## 4. Data Model Design
No database needed for this corporate website. All content is static.

## 5. Backend / Third-party Integration Plan
- No Supabase needed for this static corporate website
- No Shopify needed (not an e-commerce site)
- No Stripe needed
